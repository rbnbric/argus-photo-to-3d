How this selection was made

Surface planes, example patches, and object exclusions were marked by inspection. A deterministic color classifier finds connected material pixels within those boundaries. Only fully owned patches can enter the repeat. This is guided segmentation, not automatic recognition of every object.

The broad illumination fit uses the selected material alone. Relief is inferred from image detail; roughness is an assumed material setting. The regional mesh is a flat UV patch with holes, without recovered metric dimensions.
